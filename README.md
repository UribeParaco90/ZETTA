# ZETTA

Landing page para una plataforma de gestión académica orientada a colegios y universidades.

## Descripción
ZETTA permite centralizar la gestión de matrículas, calificaciones, asistencia y configuración institucional en una sola solución. La interfaz está pensada para una presentación comercial moderna, con diseño oscuro, glassmorphism y navegación clara.

## Estructura del proyecto
- `index.html`: estructura principal del sitio y contenido del landing page.
- `css/styles.css`: estilos personalizados, paleta de colores, layout responsivo y componentes visuales.
- `vendor/bootstrap/`: archivos del framework Bootstrap usados para la base visual y componentes interactivos.

## Cómo abrirlo
1. Descarga o clona el proyecto.
2. Abre `index.html` en tu navegador preferido.
3. Si quieres servirlo localmente, puedes ejecutar:

```bash
python -m http.server 8000
```

Luego entra en `http://localhost:8000`.

## Personalización
Puedes modificar texto, precios, módulos, colores y contenido de la sección de contacto desde `index.html` y `css/styles.css`.
